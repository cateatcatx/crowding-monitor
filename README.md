# AI硬件股交易拥挤度监控

量化 MU / SNDK / WDC / SK海力士 / 三星电子 的交易拥挤度, 在"筹码集中+动量过热"进入危险区时提前预警, 用于回撤保护(参考2026年6月25日存储股崩盘复盘)。

## 日常使用

**方式一: 网页看板(推荐)** —— 双击 `D:\investment\start_crowding_dashboard.cmd`, 自动打开 http://127.0.0.1:5690/

- 首屏: TCI总指数大数字 + 红区/触发减仓统计 + 波动余震指标 + 近6日走势
- 个股明细表(综合分/7子指标热力着色/已实现波动率/信号旗标), SK海力士每日外资净买卖(ALL全市场合计及KRX/NXT分项), TCI近一年走势图, 五标的分数图, 波动率监测(RV年化+波动分位均值余震线), 期权快照(含IV/RV), 操作对照表
- 服务器每30分钟自检, 数据超过6小时自动后台刷新; 也可点页面"更新数据"按钮手动刷新(约40秒)
- 脚本会检测端口, 重复双击只会打开浏览器不会重复启动

### 半导体 / 软件轮动（SOXX / IGV）

- 首屏卡片下方新增独立轮动模块，可切换近3个月 / 近1年。
- 相对强度 `RS = (SOXX收盘价 / IGV收盘价) / 基准日比值 × 100`，基准日为近一年窗口首个共同交易日；切换窗口不改变RS基准。
- 上图显示RS及20/60个共同交易日均线；下图显示两ETF在所选窗口分别归一到100的价格走势。
- 5/20/60日相对涨跌幅为 `(今日比值 / N个共同交易日前比值 - 1) × 100%`，不是两ETF涨跌幅直接相减。样本不足显示“—”。
- 上升表示半导体相对占优，下降表示软件相对占优；不是RSI、估值或独立买卖信号，也不参与TCI计算。
- 数据源为Yahoo Finance日线close（不含分红再投资），仅使用已完成日线与共同交易日，不前值填充。均线在截取展示窗口之前计算。
- 本地刷新、静态构建和命令行日报均已接入。配对缓存 `data/SOXX_IGV.csv` 原子替换；任一腿抓取失败/日期不一致/返回更旧数据时保留旧缓存并告警。
- 日线完整性和新鲜度按美股交易日历判断（`exchange_calendars` 的XNYS常规时段，适用于这两只美国ETF），包含节假日、夏令时和提前收盘。仅在存在已收盘且已过30分钟落地缓冲、但缓存尚未覆盖的交易日时提示待更新，替代“超过4个自然日”规则。
- 页面显示最近已收盘交易日、市场状态、休市日期、下一次收盘的北京时间，以及最近成功抓取时间。静态页面每分钟根据内嵌交易日历更新状态，不把开着的页面一直当成构建时的市场状态；日历过期时要求刷新。日期新鲜度只判断日线覆盖，不代表数据源未延迟或数据内容绝对准确。
- 例如北京时间2026-09-08晚间：9月5–6日周末、9月7日Labor Day休市，9月8日美股未收盘，所以最新已完成日线仍是9月4日；9月8日的日线要到北京时间9月9日04:00收盘后才形成。次日自动抓取成功后更新。
- GitHub Actions跨运行缓存配对日线；首次运行或缓存不可用时回退到仓库种子数据。
- 单独刷新：`python relative_strength.py`；仅读取缓存：`python relative_strength.py --no-fetch`。

### AI 硬件 / 软件 Forward P/E

- SOXX / IGV 轮动模块下方展示两条交互估值曲线：AI硬件代理为 **S&P 500 Semiconductors**，AI软件代理为 **S&P 500 Application Software**。行业包含非AI业务，成分并不等同SOXX/IGV，也不是纯AI组合估值。
- 来源：Yardeni Research / LSEG Datastream / S&P。Forward P/E = 价格 ÷ 未来12个月一致预期每股经营盈利（NTM）；与TTM市盈率区分，不参与TCI评分。
- `digitize_forward_pe.py` 用RapidOCR识别年份、PE刻度和最新图例，结合边框/刻度线校准坐标，再提取蓝色曲线的像素中位数。校准失配、末端与图例不符、数据日期倒退时拒绝替换旧数据。
- **历史数值为图片反推估算，不是真实逐日一致预期数据。** 对像素采样做日历日线性插值（含周末和休市日），不外推到图例日期之后。当前横向分辨率约硬件4.93、软件6.72自然日/像素；显示两位小数仅用于保存，不代表该精度。图例遮挡或缺失区留空；原图本身不能恢复的尖峰也无法精确恢复。
- 最新图例值和以后每天实际采集的图例值单独存为 `observations`，在对应日期覆盖像素估算；不会将历史插值伪装成图例观测。`low/high` 是像素列可见值包络，不是统计置信区间。
- 支持3个月/1年/3年/5年/全部、自定义日期范围、悬浮读数、指定日期查询、最近20日明细和所选区间CSV导出。原图折叠保留，可放大核对日期、数据口径及来源。
- 本地刷新、命令行抓取及静态构建均接入 `forward_pe.py`。原图、反推数值、历史图例读数、抓取时间和错误状态原子保存于 `data/FORWARD_PE.json`。相同图片复用已核验反推结果；每张图最多尝试3次，失败分别保留旧图与旧序列。原图日期超过7天会告警；抓取时间与数据日期分别显示。
- GitHub Actions每天北京时间约 **09:17、13:47** 检查（后者补跑），工作日 **19:30** 再检查；数据源休市或尚未发布新图时保留原数据日期。估值在其他行情管线之前独立刷新，结果和状态直接提交回仓库main，避免Actions缓存淘汰丢失图例历史。只提交该公开数据文件。
- 估值刷新失败时仍可发布旧结果，但Actions最终标失败并在摘要中记录源日期。定时任务是GitHub尽力调度，可能延迟；第三方源也可能中断，因此不能保证每天有新行情数据。每日持久化提交同时保留仓库活动记录。参见 [GitHub定时事件限制](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。
- `python forward_pe.py` 单独刷新；`python forward_pe.py --no-fetch` 检查缓存。`python build_static.py --no-fetch` 完全离线构建；CI用 `--skip-forward-pe` 复用独立刷新步骤结果。

## 信号体系(2023-2026回测标定)

**TCI 主题总指数(单一数值, 0-100)** = 0.45x强度 + 0.30x广度 + 0.25x持续
- 强度 = 5标的综合分等权均值; 广度 = 综合分>=80的标的占比; 持续 = 近10日中">=60%标的同时过热"天数比例
- 阈值: **>=80红**(样本31天, 61%在20日内遭遇>=10%主题回撤, 26%遭遇>=15%) | 70-80橙 | 55-70黄 | <55绿
- 全样本中位数仅26.9, 信噪比高; 四段历史红区: 2024/04(-10.6%)、2025/10-11(-16.4%)、2026/01-02(-9.5%)、2026/05-06(-22.2%)
- 边界: 只抓"过热顶", 不预警拥挤释放后的下跌中继顶(2024/07、2026/03等TCI仅22-32) —— 需配合个股触发器

个股综合分:

| 等级 | 综合分 | 动作 |
|------|--------|------|
| 绿 正常 | <60 | 正常持仓 |
| 黄 偏热 | 60-75 | 不加仓 |
| 橙 过热 | 75-85 | 检查期权保护成本, IV低则买3个月5-10% OTM put spread |
| 红 拥挤极值 | >=85 | 建collar或减仓20-30%; TCI>=80时主题整体降风险 |
| 触发 | 15日内曾>=85 且 收盘破MA20 | 执行减至半仓, 站回MA20且分数<60才恢复 |

关键回测结论:
- 红区(>=85, 且距250日高点15%以内)状态下, 未来20日最大回撤中位数 -6%~-28%, 出现>=15%回撤的概率 17%~40% (各标的不同), 是非红区的3-10倍。
- 但红区首触发后40日内最大**涨幅**中位数也有+16% (5/13 MU变红后又涨了51%到6/25) => 拥挤度是**条件**不是**定时器**, 正确动作是对冲/趋势破位减仓, 不是立即清仓。
- 6.25事件: MU 5/13变红, 海力士5/15, 三星5/29; 6/3起红橙广度达4/5; 6/25主题分84.3=历史99.9分位。两段式规则7/1触发(MU收1032, 后跌至938)。

## 综合分构成

| 子指标 | 权重 | 含义 | 计算 |
|--------|------|------|------|
| turnover | 15% | 成交额热度 | 20日均成交额/250日均成交额, 滚动2年百分位 |
| vol_share | 10% | 成交额占比(挤占市场) | 20日均成交额/市场基准(SPY或KOSPI), 百分位 |
| extension | 20% | 价格偏离 | 收盘/50日均线-1, 百分位 |
| momentum | 15% | 动量过热 | 60日涨幅, 百分位 |
| rsi | 10% | 短期超买 | RSI(14)原值 |
| volatility | 15% | 波动放大(末段特征) | 20日已实现波动率, 百分位 |
| basket_corr | 15% | 篮子共振(被当成一个交易) | 6标的20日平均两两相关系数x100 |

期权维度(快照, 无法回测历史): ATM IV、25Δ skew(call-put)、PC比、近月OTM call OI集中度。
skew收敛至>-3%且PC(量)<0.7 = call投机拥挤加重; IV低+分数红 = 买保护的黄金窗口。

## 数据源与局限

- 新浪美股日线(akshare stock_us_daily)、Naver韩股siseJson与投资者趋势、CBOE delayed options —— 全部免费无鉴权。
- SK海力士外资流向主指标取ALL全市场口径(KRX+NXT), 并显示KRX/NXT分项; 数据为每日净买卖股数, 正值净买入、负值净卖出, 不代表实际跨境资金划转, 也不是精确韩元成交金额。
- 无法覆盖的拥挤度维度: 空头兴趣(FINRA双周)、13F机构持仓、杠杆ETF资产规模(这次韩国2x单股ETF是崩盘放大器)、券商PB持仓数据。重大信号请人工交叉验证。
- SNDK上市仅1年多, 百分位失真(6月只给到71分), 短史标的看子指标绝对值而非综合分。
- 拥挤度是必要条件不是充分条件: 高分不必然马上跌, 但2026-06这种"5标的全红+广度4/5+主题99.9分位"的组合历史上只出现过3次(2025-10/2025-11/2026-06), 后两次60日内主题回撤-16%和-24%。
