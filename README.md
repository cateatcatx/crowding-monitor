# AI硬件股交易拥挤度监控

量化 MU / SNDK / WDC / SK海力士 / 三星电子 的交易拥挤度, 在"筹码集中+动量过热"进入危险区时提前预警, 用于回撤保护(参考2026年6月25日存储股崩盘复盘)。

## 日常使用

**方式一: 网页看板(推荐)** —— 双击 `D:\investment\start_crowding_dashboard.cmd`, 自动打开 http://127.0.0.1:5690/

- 首屏: TCI总指数大数字 + 红区/触发减仓统计 + 波动余震指标 + 近6日走势
- 个股明细表(综合分/7子指标热力着色/已实现波动率/信号旗标), SK海力士每日外资净买卖(ALL全市场合计及KRX/NXT分项), TCI近一年走势图, 五标的分数图, 波动率监测(RV年化+波动分位均值余震线), 期权快照(含IV/RV), 操作对照表
- 服务器每30分钟自检, 数据超过6小时自动后台刷新; 也可点页面"更新数据"按钮手动刷新(约40秒)
- 脚本会检测端口, 重复双击只会打开浏览器不会重复启动

**方式二: 命令行日报**

```bash
python daily_monitor.py            # 拉数据 + 算分 + TCI + 期权快照 + 红黄绿灯日报
python daily_monitor.py --no-fetch # 用已有数据重算(盘中快速刷新)
```

建议每天收盘后看一次(美股收盘后北京时间早上, 韩股收盘后下午)。

## 信号体系(2023-2026回测标定)

**TCI 主题总指数(单一数值, 0-100)** = 0.45x强度 + 0.30x广度 + 0.25x持续
- 强度 = 5标的综合分等权均值; 广度 = 综合分>=80的标的占比; 持续 = 近10日中">=60%标的同时过热"天数比例
- 阈值: **>=80红**(样本31天, 61%在20日内遭遇>=10%主题回撤, 26%遭遇>=15%) | 70-80橙 | 55-70黄 | <55绿
- 全样本中位数仅26.9, 信噪比高; 四段历史红区: 2024/04(-10.6%)、2025/10-11(-16.4%)、2026/01-02(-9.5%)、2026/05-06(-22.2%)
- 边界: 只抓"过热顶", 不预警拥挤释放后的下跌中继顶(2024/07、2026/03等TCI仅22-32) —— 需配合个股触发器

个股综合分:

| 等级 | 综合分 | 动作 |
|------|--------|------|
| 绿 正常 | <60 | 正常持仓 |
| 黄 偏热 | 60-75 | 不加仓 |
| 橙 过热 | 75-85 | 检查期权保护成本, IV低则买3个月5-10% OTM put spread |
| 红 拥挤极值 | >=85 | 建collar或减仓20-30%; TCI>=80时主题整体降风险 |
| 触发 | 15日内曾>=85 且 收盘破MA20 | 执行减至半仓, 站回MA20且分数<60才恢复 |

关键回测结论:
- 红区(>=85, 且距250日高点15%以内)状态下, 未来20日最大回撤中位数 -6%~-28%, 出现>=15%回撤的概率 17%~40% (各标的不同), 是非红区的3-10倍。
- 但红区首触发后40日内最大**涨幅**中位数也有+16% (5/13 MU变红后又涨了51%到6/25) => 拥挤度是**条件**不是**定时器**, 正确动作是对冲/趋势破位减仓, 不是立即清仓。
- 6.25事件: MU 5/13变红, 海力士5/15, 三星5/29; 6/3起红橙广度达4/5; 6/25主题分84.3=历史99.9分位。两段式规则7/1触发(MU收1032, 后跌至938)。

## 综合分构成

| 子指标 | 权重 | 含义 | 计算 |
|--------|------|------|------|
| turnover | 15% | 成交额热度 | 20日均成交额/250日均成交额, 滚动2年百分位 |
| vol_share | 10% | 成交额占比(挤占市场) | 20日均成交额/市场基准(SPY或KOSPI), 百分位 |
| extension | 20% | 价格偏离 | 收盘/50日均线-1, 百分位 |
| momentum | 15% | 动量过热 | 60日涨幅, 百分位 |
| rsi | 10% | 短期超买 | RSI(14)原值 |
| volatility | 15% | 波动放大(末段特征) | 20日已实现波动率, 百分位 |
| basket_corr | 15% | 篮子共振(被当成一个交易) | 6标的20日平均两两相关系数x100 |

期权维度(快照, 无法回测历史): ATM IV、25Δ skew(call-put)、PC比、近月OTM call OI集中度。
skew收敛至>-3%且PC(量)<0.7 = call投机拥挤加重; IV低+分数红 = 买保护的黄金窗口。

## 数据源与局限

- 新浪美股日线(akshare stock_us_daily)、Naver韩股siseJson与投资者趋势、CBOE delayed options —— 全部免费无鉴权。
- SK海力士外资流向主指标取ALL全市场口径(KRX+NXT), 并显示KRX/NXT分项; 数据为每日净买卖股数, 正值净买入、负值净卖出, 不代表实际跨境资金划转, 也不是精确韩元成交金额。
- 无法覆盖的拥挤度维度: 空头兴趣(FINRA双周)、13F机构持仓、杠杆ETF资产规模(这次韩国2x单股ETF是崩盘放大器)、券商PB持仓数据。重大信号请人工交叉验证。
- SNDK上市仅1年多, 百分位失真(6月只给到71分), 短史标的看子指标绝对值而非综合分。
- 拥挤度是必要条件不是充分条件: 高分不必然马上跌, 但2026-06这种"5标的全红+广度4/5+主题99.9分位"的组合历史上只出现过3次(2025-10/2025-11/2026-06), 后两次60日内主题回撤-16%和-24%。
